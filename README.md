# 👾 Alien Invasion

Earth is under alien attack! Aliens plummet from the sky, and you are humanity's last defense. Wield your rapid-fire rocket launcher to blast them mid-air before they crash into the city below.

---

## 🚀 Live Web Version (Ready for Vercel)

This repository includes a full-featured, zero-latency **HTML5 Canvas / Web version** ready to be deployed instantly on [Vercel](https://vercel.com):

- **Instant Play**: 0 download wait time, pure static web build with Web Audio API sound effects.
- **Controls**:
  - `←` `→` or `A` `D`: Move ship
  - `Space`: Fire rockets
  - `P`: Play / Restart
  - `M`: Toggle Sound
  - **Touch Controls**: Full on-screen buttons for mobile & tablet gameplay!
- **Scoreboard**: Live score, level progression, lives remaining, and persistent high score via local storage.

### Deploying to Vercel

1. Push your repository to GitHub.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your `Alien_Invasion` repository.
4. Keep the default settings (Framework Preset: **Other**) and click **Deploy**.
